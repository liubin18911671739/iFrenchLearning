## 设计概述

### 设计原则

1. **简洁清晰**：界面简洁，信息层次分明
2. **一致性**：保持视觉和交互的一致性
3. **可访问性**：支持键盘导航和屏幕阅读器
4. **响应式**：适配桌面和平板设备

### 技术栈

| 技术 | 版本 | 用途 |
|:--|:--|:--|
| Ant Design | 5.x | UI组件库 |
| D3.js | 7.x | 知识图谱可视化 |
| React | 18.x | 前端框架 |
| TypeScript | 5.x | 类型系统 |

## 组件规范

### 按钮

| 类型 | 用途 | 样式 |
|:--|:--|:--|
| Primary | 主要操作 | 蓝色背景，白色文字 |
| Default | 次要操作 | 白色背景，灰色边框 |
| Text | 文字操作 | 无边框，蓝色文字 |
| Link | 链接操作 | 无边框，蓝色文字 |

### 卡片

```css
.card {
  background: #ffffff;
  border-radius: 8px;
  box-shadow: 0 1px 2px rgba(0, 0, 0, 0.06);
  padding: 24px;
}
```

### 标签

| 类型 | 用途 | 样式 |
|:--|:--|:--|
| 等级标签 | 显示CEFR等级 | 彩色背景 |
| 类别标签 | 显示知识类别 | 彩色边框 |
| 状态标签 | 显示状态 | 根据状态变色 |

### 进度条

```css
.progress {
  height: 8px;
  background: #f0f0f0;
  border-radius: 4px;
}

.progress-bar {
  height: 100%;
  border-radius: 4px;
  transition: width 0.3s ease;
}
```

## 交互规范

### 加载状态

- 使用 `Spin` 组件显示加载状态
- 长时间加载显示进度提示

### 错误处理

- 使用 `Alert` 组件显示错误信息
- 提供重试按钮

### 表单验证

- 实时验证，输入时显示验证结果
- 提交时再次验证
- 验证失败高亮显示错误字段

### 动画

- 页面切换：淡入淡出
- 卡片出现：从下往上滑入
- 进度变化：平滑过渡

### 响应式断点

| 断点 | 宽度 | 布局 |
|:--|:--|:--|
| xs | <576px | 单列 |
| sm | ≥576px | 两列 |
| md | ≥768px | 两列 |
| lg | ≥992px | 侧边栏展开 |
| xl | ≥1200px | 侧边栏展开 |
