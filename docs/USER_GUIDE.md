## 系统简介

iFrench Learning 是一个基于知识图谱的法语自适应智能学习系统，旨在为学习者提供个性化的法语学习体验。

### 核心特性

- **知识图谱驱动**：构建完整的法语知识体系，展示知识点之间的依赖关系
- **自适应学习**：根据学习者水平动态调整学习内容和难度
- **薄弱点诊断**：通过根因分析算法定位学习薄弱环节
- **个性化推荐**：基于学习状态推荐最适合的学习内容

### 覆盖内容

| 模块 | 内容 | CEFR等级 |
|:--|:--|:--|
| 词汇 | 3000+核心词汇，按主题分类 | A1-B2 |
| 语法 | 500+语法点，含前置依赖关系 | A1-B2 |
| 动词变位 | 300+动词变位形式 | A1-B2 |
| 性数配合 | 名词·冠词·形容词·过去分词配合 | A1-B2 |

## 快速开始

### 1. 访问系统

打开浏览器，访问系统地址：`http://your-domain.com`

### 2. 注册/登录

首次使用需要注册账号，已有账号直接登录。

### 3. 入学测试（可选）

系统会引导你完成入学测试，快速定位你的法语水平：
- CEFR分级测试（15题）
- 语法专项测试（20题）
- 词汇量测试（30题）

### 4. 开始学习

系统会根据你的测试结果，推荐适合的学习内容。

## 功能模块

### 1. 首页仪表板

首页展示：
- 学习进度统计（已学知识点、掌握率、学习时长）
- 今日推荐内容
- 学习目标进度
- 快捷入口

### 2. 学习模块

#### 词汇学习
- 按主题分类（问候、家庭、食物、颜色等）
- 支持A1-B2级别筛选
- 包含例句和发音

#### 语法学习
- 系统化的语法知识体系
- 展示知识点前置依赖关系
- 循序渐进的学习路径

### 3. 练习模块

#### 选择题
- 即时反馈
- 详细解析
- 涉及知识点标注

#### 练习类型
- 词汇选择题：词义、搭配
- 语法填空题：时态、变位、配合
- 改错题：语法错误识别
- 翻译题：中法互译

### 4. 知识图谱

可视化展示法语知识体系：
- 节点颜色表示掌握程度
  - 红色：薄弱（<50%）
  - 黄色：学习中（50-80%）
  - 绿色：已掌握（≥80%）
- 点击节点查看详情
- 支持缩放和拖拽

### 5. 诊断报告

展示学习诊断和薄弱点分析：
- 总体掌握度
- 各类别掌握度（语法、词汇、变位、配合）
- 根本原因分析
- 个性化学习建议

## 学习流程

### 推荐学习流程

```
1. 入学测试 → 了解当前水平
       ↓
2. 查看诊断报告 → 识别薄弱点
       ↓
3. 查看知识图谱 → 了解知识结构
       ↓
4. 按推荐学习 → 系统推荐最优路径
       ↓
5. 完成练习 → 巩固所学知识
       ↓
6. 查看诊断 → 分析学习效果
       ↓
7. 循环4-6 → 持续提升
```

### 学习建议

1. **每天学习**：建议每天学习30分钟以上
2. **定期复习**：系统会提醒即将遗忘的知识点
3. **关注薄弱点**：优先学习根本原因知识点
4. **多样化练习**：结合不同题型巩固知识

## 知识点说明

### 知识点状态

| 状态 | 掌握度 | 说明 |
|:--|:--|:--|
| 未掌握 | <30% | 需要重点学习 |
| 初步了解 | 30-50% | 需要加强练习 |
| 学习中 | 50-80% | 继续巩固 |
| 已掌握 | ≥80% | 可以学习后续知识 |

### 前置知识

每个知识点都有前置依赖关系。例如：
- 学习"复合过去时"需要先掌握"直陈式现在时"
- 学习"虚拟式"需要先掌握"未完成过去时"

系统会自动检查前置知识是否满足，未满足时会推荐先学习前置内容。

## 常见问题

### Q: 如何查看我的学习进度？

在首页仪表板可以看到总体统计，包括已学知识点、掌握率等。更详细的诊断请访问"诊断报告"页面。

### Q: 推荐的内容不适合我怎么办？

系统会根据你的学习状态动态调整推荐。如果你觉得推荐不合适，可以：
1. 完成更多练习，让系统更了解你的水平
2. 在诊断报告中查看薄弱点分析
3. 在知识图谱中自主选择学习内容

### Q: 如何提高学习效率？

1. **专注薄弱点**：优先学习诊断报告中标记为"根本原因"的知识点
2. **及时复习**：按照系统的复习提醒进行复习
3. **多样化练习**：结合不同题型巩固知识
4. **查看知识图谱**：了解知识结构，有针对性地学习

### Q: 学习数据会丢失吗？

不会。你的所有学习数据都会保存在数据库中，即使更换设备也可以继续学习。

如有问题，请通过以下方式联系：
